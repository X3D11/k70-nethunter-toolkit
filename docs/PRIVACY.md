# 隐私保护与审计范围

发布使用明确文件白名单，而不是从原工作区删除几个敏感文件后整体上传。未纳入 Git 历史、分区镜像、设备数据库、日志、个人目录、附件、账号、令牌、密钥、第三方 APK/rootfs 或厂商二进制。

公开脚本中的 Android 包名、标准设备目录和内核版本是技术配置，不是个人设备标识。发布清单中的 SHA256 仅对应本公开包内文件。

不得把“未找到指定类或数据库”理解成不存在任何遥测；静态字符串命中也不是执行证据。审计应区分代码能力、启用条件、实际触发以及实际传输内容。采集真实通信内容前需获得相关人员授权，并最小化收集。

即使源码没有私人数据，运行工具生成的输出也可能含设备信息。默认不要把运行产物提交到仓库；检查后再单独分享。
