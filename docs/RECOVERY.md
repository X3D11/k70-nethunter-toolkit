# 恢复与回滚

公开包没有携带任何人的设备备份或可刷入镜像。

内核操作应使用自己的原始镜像恢复对应槽位与分区。Boot 与 init_boot 的职责不同，禁止猜测恢复目标；不要重新锁定跨区或修改系统设备的 Bootloader。

隐私示例中的 restore.sh 只清理本模块命名的规则并恢复 Analytics/MSA 的默认状态；只有原状态确为默认时才适用。原先手动启用、禁用或不同用户的设备，应根据备份恢复真实状态。

停用 Magisk 模块不会自动撤回通过 PackageManager 设置的停用状态。请明确执行审核后的恢复步骤，再处理模块。不要使用清空全部 iptables 规则作为恢复方法。

恢复脚本是参考实现，不保证适配所有 ROM。建议先在有控制台和离线恢复条件的测试设备验证。
